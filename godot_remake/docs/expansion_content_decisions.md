## 1. 证据分类口径

本工程统一使用四分类：

| 分类 | 定义 | 本版本数量 |
|---|---|---|
| local_version_confirmed | 指定本地受控文本中有精确 token 支持 | 108 |
| local_version_partial | 仅确认名称、局部行为或局部文本 | 5 |
| singleplayer_extension | 本项目原创单机设计 | 65 |
| evidence_gap | 当前没有足够本地证据 | 0 |

禁止把"地图名称出现""图片文件存在""脚本文件名类似"当作完整机制证据。本版本所有 confirmed 条目的 token 均由构建器在 `work/v142/text/moyu_*.strings.txt` 逐条精确命中后才写入。

## 3. 单机原创扩展（singleplayer_extension，必须声明为原创）

以下内容**不是原版还原**，是本项目为单机长线扩展设计的：

1. 固定冒险者名册（12 首批 + 24 候补）：原版只有"朋友"系统，无"固定冒险者"名册与委托体系；名册为本项目原创设计（v1.43）。
2. 拍卖会（v1.46）：原版朋友/资源入口不代表存在完整拍卖行；封闭市场为本项目原创（总计划书 2.3 明确要求标 singleplayer_extension）。
3. 异步排行榜（v1.45）：原版排行榜入口存在，但单机异步 PvP/榜单计算为本项目原创。
4. NPC 日结经济（v1.44）：固定冒险者每日抽象日结为本项目原创。
5. 产业/城堡经营（v1.47）、十四日赛季（v1.54）、收藏图鉴（v1.53）：均为原创长线系统。
6. 主线/支线/冒险者委托中的原创任务（quest_main_black_abyss、quest_side_rose_lake、quest_adv_* 等 32 条）仅借用地图/物品 token 背景，任务本身为本项目设计。

## 4. 刻意未纳入候选目录的内容及原因

1. **2.2 的机制结论**：FFDec 对 2.2 动作码翻译失败（Invalid property index 系列，约 1.8GB 错误日志，p-code 为空），因此 2.2 只保留字符串级别证据，机制/坐标/拓扑不纳入任何 confirmed 条目。
2. **答题系统的具体题库**：本地存在大量历史/文学/科学问答 token（三国演义、四大名著、温度计等），但完整题库机制未确认，本次仅登记"答题/声望任务"系统级 token，不逐个登记题目。
3. **婚姻/恋爱完整规则**：token 表明存在恋人/爱人/分手/永久失去朋友等文本，但完整关系数值、触发与结局规则未确认；恋爱作为可选文本关系默认方案（v1.43 决策表），本次不登记为 confirmed 机制。
4. **家族/军团玩家组队玩法**：本地有军团/军衔/爵位/军团管理员 token，但"玩家可加入军团"的联网行为原版存在与否未确认；军团相关内容仅登记为系统/挑战背景（军衔任务、军团管理员挑战），不声称完整军团玩法。
5. **各类"战场/郊区/幻境"子区域**：本地有 南城战场/郊区/幻境、冰宫战场/郊区/幻境 等大量区域名 token，本次仅登记主要野外/城镇候选，细分子区域留待对应版本实现时选择（避免目录膨胀且证据仅为名称级）。
6. **所有"精英/头目/护卫"怪物系列**：本地有巨杰士/恐兽/提风/龙怪/炎女/四牙怪/绿魔精/守卫魔/冰妖剑士/刺虫人/鹿角兽/黑翼法师/死神战将 等大量头目/精英/护卫 token；本次仅登记 11 个代表性 Boss，不逐个登记普通怪头目变体（避免与现有 data/monsters.json 及怪物图谱重复登记）。
7. **截图/视觉素材**：本版本严格不处理任何非文本附件；SWF 内图片资源一律不导入、不引用。
