## 1. 结果摘要

v1.44 让 12 名固定冒险者按可保存种子做日结，发邮件，并基于真实账本直接交易。存档保持 v22，启用 `day_sequence`、`mailbox`、`economy.adventurer_ledgers`、`economy.daily_settlement_log`。入口仍是卡萨诺日常任务官「冒险者公告板」，不新增地图演员。新档第 1 天不在 `_ready` 结算。

## 2. 生产调用链

`GameState.advance_day` 先记下 `ended_day=current_day`，再 +1，然后 `DayCycleService.settle_ended_day`。日结随机只用 `world_seed + ended_day + system_id + adventurer_id + event_sequence` 的 FNV-1a32，不调 `randi`。

公告板 → 邮件面板 / 交易面板 → `GameState.claim_mail` / `send_player_mail` / `buy_from_adventurer` / `sell_to_adventurer` → MailService / MarketService 纯函数返回新 expansion → GameState 一次性提交。

送礼成功后 `MarketService.credit_item` 把物品记入 NPC 账本。生产无 `transfer_item_to_npc`。UI 不直接写 mailbox / ledgers / inventory。
