### 3.1 NPC主页

将 `_open_actor_dialogue("research")`迁移为专属函数，例如：

`_open_research_dialogue()`

对话使用原版含义并提供四个选项：

| 原版标签 | 建议action | 行为 |
|---|---|---|
| 进入 | `research` | 打开现有 `ResearchPanel` |
| 研究所的当前信息 | `research_info` | 显示当前技术、日产量、库存、VIP及20级生产条件 |
| 关于2008奥运使者 | `research_olympic_info` | 显示2008奥运使者/五福娃技术资料的当前状态 |
| 提高产量任务 | `research_production_task` | 从NPC对话直接调用现有产量任务原子方法 |

另保留离开选项。

标签应优先使用上述SWF原文，不继续用“进入研究所”冒充原版标签。

### 3.2 当前信息

只读取现有 `GameState.research` 与 `pet_service`：

- 技术等级。
- 日产量及上限。
- 库存。
- VIP等级。
- 技术20级前不能生产。
- 当前可生产奇异兽品质/售价可按现有公式显示。

提供返回研究所主页和离开。

不得在查询时修改状态。

### 3.3 关于2008奥运使者

使用现有 `GameState.fuwa_event`：

- 五福娃任务未完成：提示寻找2008奥运使者和幻兽培养技术资料。
- 已完成但最终奖励未领取：提示先向2008奥运使者完成交付。
- `completion_claimed == true`：感谢技术资料，并显示当前有效技术上限仍为项目覆盖值300。

本分支只显示状态，不发奖、不修改VIP、不重复完成五福娃任务。

### 3.4 提高产量任务

直接调用：

`GameState.complete_research_production_task()`

要求：

- 成功：按现有规则消耗灵魂王，日产量+2。
- 缺材料：不扣灵魂王、不改产量。
- 达到日产量上限6：不扣材料、不提高产量。
- 成功或失败后返回研究所NPC对话链，并显示实际结果。
- 不复制成本或产量公式。

现有 `ResearchPanel`中的产量任务按钮保留，不要求本版本删除；它属于便捷重复入口。

### 5.3 研究所窗口结算

由研究所NPC“进入”打开同一个 `ResearchPanel` 后：

1. 资助：
   - 技术+1。
   - 魔石减少 `funding_magic_stones_per_level`。
2. 购买：
   - 库存-1。
   - 幻兽+1。
   - 魔石减少购买前由 `research_pet_price()`算出的实际售价。
3. 无库存失败：
   - 库存、魔石、幻兽均不变。

产量任务的资源扣除由NPC“提高产量任务”分支测试：

- 灵魂王减少 `production_task_cost()`。
- 日产量+2。

所有成本均从现有service/config读取，不在测试中复制常量。
