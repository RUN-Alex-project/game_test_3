## 2. 逻辑修复

修改：

`scripts/main_original.gd`

在 `_open_research_olympic_info()` 中使用：

- `found_count = int(GameState.fuwa_event.get("found_count", 0))`
- `completion_claimed = bool(GameState.fuwa_event.get("completion_claimed", false))`

分支顺序：

1. `completion_claimed == true`
   - 显示已收到技术资料。
   - 显示当前有效技术上限300，必须从config读取。
2. `found_count >= GameState.FUWA_NAMES.size()` 且未领取
   - 显示五福娃已找齐/技术资料已准备好。
   - 提示向2008奥运使者完成最终交付。
3. 其他
   - 提示寻找2008奥运使者并打听幻兽培养技术。

不得再使用 `beast_defeated`代表最终待交付状态。

该函数保持只读，不得：

- 调用 `claim_fuwa_completion()`。
- 修改 `fuwa_event`。
- 修改研究所VIP。
- 修改魔石。
