## 3. 独立SWF证据文件

### 3.1 生成来源

使用实际命令反查 `魔域1.03_v9.swf`：

```powershell
python ..\work\dump_sprite_actions.py <SWF绝对路径> 1184
python ..\work\dump_sprite_actions.py <SWF绝对路径> 1183
python ..\work\dump_sprite_actions.py <SWF绝对路径> 1206
python ..\work\dump_sprite_actions.py <SWF绝对路径> 1161
python ..\work\dump_sprite_actions.py <SWF绝对路径> 827
```

将与本任务相关的常量、变量名和选项文本整理为UTF-8纯文本证据文件。文件必须记录：

- 原SWF文件名。
- 反查脚本。
- sprite ID。
- 原始选项文本。
- 关键变量/函数token。
- 与Godot action的映射说明。

不得手写成只有结论的摘要；必须保留足以复核的ActionScript常量/token片段。

### 3.2 注册表改造

对原版选项：

- `evidence_source`指向新的 `res://docs/evidence/...txt`。
- `evidence_tokens`使用能在证据文件中准确命中的原版文本/token。
- `implementation_path`继续指向Godot实现。
- 不得让 `evidence_source == implementation_path`。

对于项目专属便捷选项或改版差异：

- 增加 `classification`，建议值：
  - `native_confirmed`
  - `convenience_override`
  - `intentional_divergence`
  - `evidence_gap`
- 原版事实和当前项目规则分字段记录，不能混写成一句无法判断来源的描述。

至少对全部19个现有选项完成分类；不能只修六个新action。

### 3.3 元帅缺口

`evidence_gaps`必须分别登记：

1. 原版“军情查询”：BOSS行踪文本，当前未实现独立入口。
2. 原版“关于军衔”：军功来源与军衔说明，当前未实现独立入口。

当前“国王消息”是项目现有故事入口，不得再用“军情/消息分支”描述成原版等价项；应分类为项目实现或差异。

### 3.4 已作出的PM决定

注册表必须落实：

- 75,000,000金币档保留为 `convenience_override`，只存在于VIP便捷聚合窗。
- 日常官当前“魔魂晶石500、灵魂王2000”保持不变，标为 `intentional_divergence`。
- 原SWF“灵魂晶石/灵魂王及500功勋”单独记录为原版证据。
- 本整改不实现元帅“军情查询”和“关于军衔”。

## 4. 专项测试补齐

继续使用：

`tests/test_native_npc_progression_routes_scene.gd`

### 4.1 公主周日礼物

必须从：

`_open_actor_dialogue("princess") -> 点击“星期天礼物”`

开始，验证：

- 成功领取后物品增加、领取日写入。
- 第二次尝试不重复增加物品。
- `progression_panel`始终隐藏。

测试夹具必须显式设置满足领取条件的好感/关系状态，不能依赖其他测试残留。

### 4.2 周一/周二材料交付

必须分别：

- `current_day = 1`，从日常官NPC入口完成一种材料交付。
- `current_day = 2`，清理对应每日完成标记后，再从日常官NPC入口完成另一种材料交付。

两次都要通过可见对话按钮触发，不能用 `_handle_dialogue_action()` 直接代替入口验收。

保留重复交付和材料不足不扣资源断言。

### 4.3 研究所端到端

必须先：

`_open_actor_dialogue("research") -> 点击“进入研究所”`

在由该入口打开的同一个 `ResearchPanel` 实例上继续测试：

1. 资助成功：技术等级增加、魔石按现有规则扣除。
2. 产量任务成功：灵魂王扣除、日产量+2。
3. 购买成功：库存减少、魔石扣除、幻兽增加。
4. 至少一条失败路径，建议无库存或材料不足：
   - 相关资源不变。
   - 不产生幻兽。
5. 全程 `progression_panel`保持隐藏。

相邻测试 `test_native_research_flow_scene`继续保留，但不能替代本段。

### 4.4 注册表断言

扩展专项测试，至少断言：

- JSON可解析。
- 恰有5组NPC、19个登记选项。
- 每项包含 `classification`。
- `evidence_source`存在，全部 `evidence_tokens`命中。
- `native_confirmed`项目的 `evidence_source`不得等于 `implementation_path`的文件部分。
- `implementation_path`文件存在，对应action或函数token能在实现文件中命中。
- `evidence_gaps`分别包含“军情查询”和“关于军衔”。
- 75,000,000便捷档和日常官数值差异具有PM决定分类。
