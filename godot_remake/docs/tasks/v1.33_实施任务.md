# v1.33 实施任务：活动主场景退役旧地图/战斗面板

执行角色：资深开发工程师  
规划与验收角色：项目经理 / 系统工程师  
前置版本：v1.32已复验通过  
目标测试总数：48个自动化场景 + 主场景冒烟测试  
存档影响：无，继续使用v21

## 1. 目标

从当前活动主场景 `scripts/main_original.gd` 中彻底移除隐藏的旧 `MapPanel` 和 `BattlePanel` 运行时依赖，确保所有地图移动继续只走场景边缘入口，所有战斗继续只在当前地图演员上发生。

本版本处理“活动运行时退役”，不同时删除历史脚本和素材。这样可以把运行时去耦与物理文件清理拆成两个可独立回滚、独立验收的步骤。

## 2. 当前问题

活动主场景虽然已经不显示旧地图/战斗窗口，但仍然：

- preload `map_panel.gd` 和 `battle_panel.gd`。
- 声明 `map_panel` 和 `battle_panel` 成员。
- 在 `_build_panels()` 中实例化、连接并隐藏两个面板。
- 在关闭所有面板的列表中继续处理这两个实例。
- 部分测试通过读取 `main.battle_panel.visible` 证明它没有弹出，这反而固定了旧实例必须存在。

风险是后续入口误接信号时旧面板可能重新出现，同时活动主场景承担不必要的资源加载和状态维护。

## 3. 必须修改

### 3.1 活动主场景

修改 `scripts/main_original.gd`：

1. 删除 `MapPanel` 和 `BattlePanel` preload。
2. 删除 `map_panel` 和 `battle_panel` 成员声明。
3. 删除 `_build_panels()` 中两个旧面板的创建、信号连接、`add_child` 和 `hide`。
4. 从关闭面板集合中删除两个旧成员，避免访问不存在字段。
5. 保留 `_start_battle(monster_id)` 作为旧动作路由兼容入口，但它只能：
   - 在当前地图的 `interactive_actors` 中查找对应怪物并调用场景内战斗入口。
   - 找不到时显示“当前场景中找不到该怪物。”。
   - 不创建、加载或显示任何战斗面板。
6. 保持 `NativeExitButton` 和 `_travel_to()` 现有行为，不引入地图选择窗口。

### 3.2 旧断言迁移

更新以下活动测试/捕获脚本，使其不再读取已删除的 `main.battle_panel` 字段：

- `tests/test_main_scene.gd`
- `tests/test_scene_battle_scene.gd`
- `tests/capture_v112_scene_battle.gd`

新断言应检查：

- 主场景树中不存在脚本路径为 `res://scripts/map_panel.gd` 或 `res://scripts/battle_panel.gd` 的节点。
- 调用 `_start_battle()` 后由 `SceneBattleController` 接管当前地图怪物。
- 不存在任何独立战斗窗口。

检查 `tests/visual_battle_scene.gd/.tscn`。该旧手工场景直接调用 `main.battle_panel._attack()`：

- 优先将其改成使用当前场景怪物和 `SceneBattleController` 的手工演示。
- 如果与已有 `visual_scene_battle` / `capture_v112_scene_battle` 完全重复，可在报告中给出引用搜索证据后删除；不得留下无法实例化的测试场景。

### 3.3 新增专项测试

新增一个独立测试场景，建议命名：

- `tests/test_no_legacy_panels_scene.gd`
- `tests/test_no_legacy_panels_scene.tscn`

至少覆盖：

1. 实例化活动主场景后，递归检查场景树没有 `map_panel.gd` / `battle_panel.gd` 节点。
2. 读取 `main_original.gd` 文本，确认不再 preload 两个旧脚本，也没有 `var map_panel` / `var battle_panel`。
3. 在有目标怪物的地图调用 `_start_battle()`，断言场景战斗目标被正确锁定。
4. 对不存在于当前地图的怪物调用 `_start_battle()`，断言只更新状态提示，不创建面板。
5. 点击一个原版场景边缘出口，断言地图切换仍由 `NativeExitButton` 完成。
