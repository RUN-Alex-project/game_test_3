## 1. 任务目标

修复 `tests/test_swf_evidence_registry_scene.gd` 中runtime资源活动来源保护未执行的问题，使合法scope=`runtime`的资源在具有`source_refs`时，至少存在一个非legacy来源。

## 2. 事实依据

当前合法scope：

```gdscript
["runtime", "active+legacy", "legacy"]
```

当前错误判断：

```gdscript
if scope == "active" or scope == "active+legacy":
```

注册表没有合法的`active`值，绝大多数活动资源使用缺省`runtime`。该判断导致runtime保护分支失效。

PM/SE人工审计确认当前数据本身无错：

- 107个runtime资源。
- 带source_refs的runtime资源中，仅legacy来源数量为0。
- path/token错误数量为0。

本任务只修测试保护，不修数据。

## 3. 必须修改

修改：

`E:\deepseek-work\TKS3_mod\godot_remake\tests\test_swf_evidence_registry_scene.gd`

将活动来源条件修正为：

```gdscript
if scope == "runtime" or scope == "active+legacy":
    assert(has_active_ref, "active-scope image %s has no non-legacy source_ref" % str(img["image_id"]))
```

可同步把错误信息改成更准确的：

```gdscript
"runtime/active+legacy image %s has no non-legacy source_ref"
```

不得增加`active`到合法scope枚举来绕过问题；当前schema权威值是`runtime`。
