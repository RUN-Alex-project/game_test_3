## 10. 验收复核补遗（2026-08-21）

第 4 节的门禁证据已在开发机独立复现，结论不变。补遗只针对第 9 节的**适用范围**：
按仓库策略有三类输入不入库，干净克隆缺这三类东西，第 9 节命令会以难定位的错误失败。

| 未入库输入 | 影响 | 修法 |
|---|---|---|
| Godot 导入缓存 `.godot/` 与 `*.import` | 全量在第 3 个场景报 `No loader found for resource` | `godot --headless --path . --import`（`*.import` 已随本次补遗入库，克隆后仍需生成一次缓存） |
| 原版 SWF（`.gitignore` 有意排除） | `test_native_timeline_registry_scene`、`test_combat_feedback_sequence_scene` 无法运行 | 放到仓库根，或设 `MOYU_SWF_PATH`；只影响这 2 个场景 |
| 发布产物 `*.exe` / `*.pck` / `build_manifest.json` / `SHA256SUMS.txt` | `DOC_GATE FAIL`、`RELEASE_GATE FAIL`、`test_release_candidate_scene` 失败 | `python work/v155/rebuild_release.py`；发布目录里的三份**文档**已入库 |

干净克隆的复跑顺序：

```powershell
cd <repo>\godot_remake
$env:GODOT_EXE = "<Godot_v4.6.3-stable_win64.exe 真实路径>"
python tools/preflight.py                       # 逐项报出缺失前置与修法
& $env:GODOT_EXE --headless --path . --import   # 生成导入缓存
python work/v155/rebuild_release.py             # 重建 exe/pck 与 manifest/SHA256SUMS
python tools/run_tests.py                       # 全量 90/90 + 冒烟
python docs/doc_gate.py
.\work\run_release_gate.ps1
```

只想跑「不需要额外输入」的部分：

```powershell
python tools/preflight.py --for-available
python tools/run_tests.py --only-available
```

`--only-available` 会把前置缺失的场景报为 `PREREQ_MISSING`（不是 PASS、不是 SKIP），
并打印与完整门禁**不同**的结束标记，避免部分运行被当成 90/90 的完整证据。

**哈希口径**：第 5 节记录的 exe/pck 哈希对应开发机那一次导出。第三方重建会得到不同哈希
（PE 时间戳等因素），此时 `DOC_GATE` 仍应 PASS（三方自一致），但不会等于第 5 节的数值。
可复现的是**测试与门禁**，不是那一个二进制。

**新增工具**：`tools/preflight.py`（前置检查）、`tools/play.ps1`（哈希校验后启动 v1.41 发布包）、
`tools/build_playable.ps1`（导出 `embed_pck=true` 单文件包到 `artifacts/playable/`，不扰动 v1.41）。
持续验证见 `.github/workflows/linux-tests.yml`。
