## 通用交付合同

每次交付必须包含：

1. 结果摘要、未完成项、刻意未做项。
2. 新增、修改、删除文件的绝对路径。
3. 数据和存档变化、默认值、迁移、兼容性。
4. 用户操作到 service 再到状态保存的实际生产调用链。
5. 本地版本借鉴、单机原创扩展、evidence_gap 的分类。
6. 正向、同验证器真实变异负向、相邻、全量、冒烟的命令和实际结果。
7. DeepSeek V4 Flash 的批量执行工作、输入、输出和复核方法。
8. 明确声明所有开发和自动化验收只使用纯文本输入、代码、数据、资源路径、节点属性、运行时状态和日志。

PM/SE 不会只凭交付报告签署；会独立抽查代码、数据、状态机、存档和关键测试。
