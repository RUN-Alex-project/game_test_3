## 1. 目标与非目标

实现第二条中期单机篇章：南部城邦与边境战线。重点是可控的四阶段守备、侦察选择、固定 NPC 协作、可复玩的边境委托，而不是无限刷怪或在线阵营战。

完成内容：

1. 6 张南部/边境地图和明确的解锁路径。
2. “侦察—补给—守备—反攻”四阶段战线状态机。
3. 3 个固定阵营 NPC、至少 2 名既有冒险者协作。
4. 2 个阶段 Boss 与 1 个边境精英委托。
5. 与军功、爵位、领地贡献、商会和排行榜的有限联动。

不做：真实阵营对抗、网络、随机无限波次、可无限叠加军功、无上限奖励循环。

## 3. 战线状态机

### 3.1 阶段

状态严格限定为：`locked`、`scouting`、`supply`、`defense`、`counterattack`、`resolved`、`weekly_contract`。

1. 侦察：完成两个不同调查目标。
2. 补给：从已有背包/商会/领地系统提交白名单内补给；禁止凭空消耗或交付。
3. 守备：完成固定次数的战斗节点，按 operation_id 去重。
4. 反攻：击败阶段 Boss；只能由真实胜利推进。
5. 收束：结算一次性奖励、军功/声望/贡献，解锁每周边境委托。

### 3.2 联动规则

1. 军功奖励必须走当前军功真实接口；本版本不得改变用户既有 Boss 军功倍率。
2. 领地贡献和商会声望只在数据登记的阶段结算一次。
3. 固定 NPC 关系影响可改变补给折扣或委托效率，但不得绕开阶段前置。
4. 守备失败、死亡、撤退、切图、旧 session 回调均不推进阶段，也不结算军功。
5. 每周边境委托最多一次；奖励/敌人快照随周种子固化。
