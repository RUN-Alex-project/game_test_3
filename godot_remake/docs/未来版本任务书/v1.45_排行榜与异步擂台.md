## 1. 版本目标

实现完全离线的排行榜、异步擂台和战报。排行榜数据来自玩家与固定 NPC 的真实持久状态；对战使用固定 NPC 的属性、装备、幻兽和技能快照，不访问网络、不显示在线状态。

---

## 2. 范围

### 2.1 必须实现的榜单

1. 战斗力榜。
2. 幻兽榜。
3. 擂台榜。
4. 探索榜。
5. 商会信誉榜预览。
6. 领地贡献榜预览。

### 2.2 必须实现的比赛

1. 练习赛：不影响积分。
2. 挑战赛：影响擂台积分和关系。
3. 赛季赛基础记录：只存赛程/积分；完整赛季在 v1.54。

### 2.3 不在范围

1. 不做拍卖、产业、城堡、新地图。
2. 不做实时多人、网络匹配、聊天室、服务器排名。
3. 不做赛季奖励、主题活动。

---

## 3. 数据与服务

### 3.1 新数据

1. data/ranking_rules.json。
2. data/arena_rules.json。
3. data/arena_opponents.json（若 NPC 数据中不便承载快照规则）。

### 3.2 新服务

1. RankingService：计算榜单、同分规则、前日变化、变化原因。
2. ArenaService：建立挑战、生成对手快照、结算战报和积分。
3. BattleSnapshotService：从真实玩家/NPC 数据构建不可变快照。

### 3.3 v22 状态

启用：

1. expansion_state.rankings。
2. expansion_state.season.arena_seed_state。
3. expansion_state.adventurers 的评分/快照字段。

每场对局至少含 match_id、operation_id、day、mode、player_snapshot、opponent_snapshot、result、score_delta、relationship_delta、settled。

---

## 4. 规则

### 4.1 排名

每个榜单必须：

1. 从实际持久化数据计算。
2. 使用稳定排序：主值、次值、稳定 ID。
3. 记录前日名次及变化原因。
4. 空榜、同分、数据缺失时有确定输出。
5. 不允许在 UI 中写死排名数组。

### 4.2 异步对战

1. 通过现有 SceneBattleController 和 CombatService 走真实战斗生命周期。
2. 对手属性只使用挑战发起时的快照；战斗过程不能因日结变化而漂移。
3. 练习赛不改变积分；挑战赛才改变积分和关系。
4. 战斗取消、切图、失败、死亡、旧 session 回调均不得结算。
5. 战报必须可保存和回看，显示双方快照摘要、模式、结果、积分变化和关系变化。

---

## 5. UI

1. 从 PK 官或现有公告板真实入口打开排行榜。
2. 排行榜面板有六个榜单页签或等价切换，不加入顶部 HUD。
3. 擂台挑战必须从 NPC 名册或 PK 官正式入口发起。
4. 长榜单可滚动/分页；空榜和未解锁榜单有文字理由。
5. 结束战斗后状态提示、战报入口和面板层级正确。

---

## 6. 强制测试

### 6.1 正向

1. 每个榜单按真实玩家/NPC 数据排序。
2. 同分排序稳定，保存/读取后不变。
3. 改变某 NPC 的真实装备/幻兽/探索状态后榜单真实变化。
4. 练习赛、挑战赛、赛季赛入口各自通过真实 UI 或对话路径。
5. 使用真实生产战斗完成至少一场挑战赛。
6. 战报准确反映双方快照和结算结果。
7. 成功后积分和关系变化；练习赛不改变积分。
8. 战斗取消、死亡、切图后不结算。

### 6.2 真实变异负向

至少八项：

1. 非法对手 ID。
2. 过期/损坏对手快照。
3. 相同 match_id 重复结算。
4. 积分为负或超范围。
5. 榜单缺少必需数据。
6. 伪造胜利结果。
7. 旧 session 回调尝试结束新 session。
8. 练习赛错误加分。
9. 同分规则被篡改。
10. 战报和结算数据不一致。

每项使用正向同一验证器，先断言变异生效，后命中精确错误码。

### 6.3 回归

1. 战斗、战斗反馈、切图、死亡、PK、关系、日结、v22 保存/加载。
2. UI 面板边界、启动隐藏、层级、状态提示。
3. 全量 runner、冒烟、doc gate、release gate。

---

## 7. 拒签条件

1. 排名是写死文本或随机数字。
2. 对战不使用真实生产战斗或使用网络。
3. 对手在战斗中读取可变 NPC 状态而非快照。
4. 取消/死亡/切图能结算积分。
5. 练习赛能修改积分。
6. 使用任何非文本附件作为开发或验收输入。
