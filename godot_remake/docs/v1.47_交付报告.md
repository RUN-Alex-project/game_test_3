## 3. 收益/扣除表

- 日产：base + 委任 + 关系；写入领地 stocks，受 stock_cap 封顶。
- 城堡升级：2 级金 200 / 爵位 0；3 级金 800 / 爵位 1；仓储 cap 10/20/40。
- 收集：gold → castle_gold；物品受仓储 cap；满则 leftover 留在领地库存，PROPERTY_WAREHOUSE_FULL。
- 事件 handle：金 0 / stock+1 或 +2 / 贡献+1 或 +2。
- 事件 fail_pay：需 50 金；金不足 → TERRITORY_EVENT_FAIL 且不扣。
- 周结：ended_day % 7 == 0 时贡献 +1，last_weekly_day 幂等。

## 4. 事件与委任状态机

事件：日结 _roll_event → pending_event_id → resolve_event(handle|fail_pay) → event_resolved + cooldown → 重复 TERRITORY_DUP_EVENT。
委任：assign(start=current_day, end=current_day+3) → expire_due 在 settle 之前 → 三个产出日。双岗 ASSIGNMENT_DOUBLE_POST；擂台/委托忙碌 ASSIGNMENT_BUSY。
