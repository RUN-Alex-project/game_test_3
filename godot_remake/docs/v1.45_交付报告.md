## 2. 生产调用链

- 排行榜：`GameState.refresh_rankings` → RankingService.rebuild（主值降序、次值降序、stable_id 升序）
- 探索分：`note_map_visit` 把 `current_map_id` 写入 `visited_maps`
- 日结 `arena_prep`：该 NPC `arena_score += 1`
- 开战：`begin_arena_match` → `engage(arena_npc:<id>, arena_proxy)`；BattleSession 经 `GameState.arena_combat_overlay` 灌入冻结战斗数据
- 胜利：`battle_finished` → `settle_arena_match`（挑战赛 +10 分、关系 +2）
- 取消/切图：`cancel_battle` → `abandon_active_arena_match`（不发 battle_finished，不加分）
- 练习赛不影响积分；赛季赛只写 `season.arena_seed_state.matches`

擂台怪不进 `monsters.json`，`victory_rewards` 对未知 ID 返回空，不掉金币/经验。
