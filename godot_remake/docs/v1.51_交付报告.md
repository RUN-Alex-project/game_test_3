## 3. 阶段与角色

locked → summons → abyss_entry → echoes → totem_trials → heart_assault → final_battle → epilogue_pending → completed → weekly_abyss。

- 前置三类：篇章（树心/南部/冰原任一完成） + 关系>=2 + 商会声望或领地贡献>=1
- 调查：gate_seal@gate、heart_seal@heart；dispatch `abyss:` → abyss_investigate
- 回响：5 个登记，完成 3 个即可；assault/guard/mystery/totem/commander
- 图腾：totem_guild 读 reputation 并扣 fruit；totem_territory 读 contribution；totem_bond 读关系值；快照入帐
- NPC：何铭 abyss_he / npc_adv_he_ming；江月 abyss_jiang / npc_adv_jiang_yue；顾宁 abyss_gu / npc_adv_gu_ning；周常 abyss_weekly
- Boss：abyss_heart_boss@heart（final_battle）、周常 abyss_weekly_trial；base_exp/merit=0
- 奖励：一次性 80 金+rose + 邮件 + 关系 + explore_score；周常 15 金+fruit，SKIP_SAME_WEEK
