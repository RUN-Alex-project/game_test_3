## 2. 必须整改

### LOGIC-134-08：2008奥运使者“待最终交付”状态判断错误

当前实现：

```gdscript
if completion_claimed:
    # 已领取
elif beast_defeated:
    # 技术资料已到手，等待最终交付
else:
    # 未完成
```

但五福娃完整流程中：

- `beast_defeated`只表示当前一轮已击败雷角风牙兽。
- 每次领取当前福娃奖励后，`beast_defeated`会恢复为false。
- 五位福娃全部找到、等待最终向2008奥运使者交付时，真实状态是：
  - `found_count == 5`
  - `completion_claimed == false`
  - `beast_defeated == false`

因此当前“已找齐但未领取最终奖励”会错误显示成“尚未找到技术资料”。

正确判断应基于：

```gdscript
found_count >= GameState.FUWA_NAMES.size() and not completion_claimed
```

### QA-134-09：2008奥运使者只读测试只覆盖一个状态

任务书要求至少覆盖未完成与已完成状态；当前测试只点击一次并断言VIP/魔石不变，没有设置和检查不同 `fuwa_event` 状态，也没有检查显示文本。

必须覆盖：

1. 未找齐：提示寻找/打听2008奥运使者。
2. 已找齐但未最终交付：提示先完成最终交付。
3. 已完成并领取：感谢技术资料并显示有效上限300。

三种状态均不得修改：

- `fuwa_event`
- 研究所VIP。
- 魔石。
