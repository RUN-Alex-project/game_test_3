## 2. 阻断准入的问题

### DQ-001：`image_0051` 被错误标记为仅 legacy

严重度：中  
置信度：高  
影响范围：无图像资源证据注册表、下一阶段legacy清理决策

注册表当前内容：

- `known_uses` 仅记录 `legacy battle_panel 暴雪骑士长（隐藏旧面板，非运行时）`。
- `scope` 被设置为 `legacy`。

当前活动代码与数据中的实际引用：

- `scripts/main_original.gd`：雷角风牙兽使用 `image_0051.png`。
- `scripts/main_original.gd`：雷鸣大陆龙怪使用 `image_0051.png`。
- `data/pets.json`：一个活动幻兽模板图标使用 `image_0051.png`。
- `scripts/battle_panel.gd`：另有legacy引用。

风险：v1.33将清理legacy地图/战斗面板。如果后续工程师相信当前注册表，可能把仍被活动主场景和幻兽数据使用的资源当成纯legacy处理。该错误直接违背“无图像模型可凭注册表安全定位资源用途”的核心目标。

## 3. 专项测试的覆盖缺口

当前测试能检查字段存在、文件存在和组件/动画角色号复用关系，但没有自动保护以下稳定规则：

1. `ui_components.id`、`animations.id`、`shared_characters.id`、`image_assets.image_id`、`maps.map_id` 各自唯一。
2. `image_assets.image_id` 与 `file` 的无扩展名文件名一致。
3. 注册表地图集合与 `data/maps.json` 完全一致。
4. 每个地图背景与 `maps.json` 一致，且对应文件已登记在 `image_assets`。
5. 标记为 `scope=legacy` 的资源不能同时被活动入口 `main_original.gd`、活动panel/controller/service或活动data引用。
6. `known_uses` 与 `evidence_source` 不得为空。

这些规则稳定、重要且维护成本低，适合写入自动化测试。人工审计已经确认除DQ-001外的当前数据满足这些规则。
