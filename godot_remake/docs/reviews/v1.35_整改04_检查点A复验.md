## 3. 补强问题A-02：neg5未锁定目标错误码

当前代码只断言：

```gdscript
assert(not n5_errs.is_empty(), ...)
```

这会允许任意无关错误冒充目标负向验证。应改为检查：

```gdscript
assert(
    Support.has_error_code(n5_errs, "SCENARIO_PRESENT_NOT_IN_REGISTRY"),
    "neg5: expected SCENARIO_PRESENT_NOT_IN_REGISTRY, got: %s" % str(n5_errs)
)
```

同时保留`not n5_errs.is_empty()`并无必要，错误码断言已经覆盖。
