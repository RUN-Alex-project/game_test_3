## 一、v1.38 综合整改（已实施）

文件：`tests/test_story_dialogue_state_machine_scene.gd`

1. **precondition_hook 由 run_registry_case 统一调度**
   - 改前：`_run_node` 单独调 `_precondition(node_id)`（读全局 `_nodes`）
   - 改后：`run_registry_case(registry, node_id)` 从传入 registry 读 `precondition_hook`，仅接受 `_precondition_impl`（唯一合法），变异 hook 为其他 → `STORY_PRECONDITION_DRIVER_MISSING`
   - 负向：N9（缺失 hook）→ DRIVER_MISSING；N10（错误 hook=setup_give_roses）→ DRIVER_MISSING；N11（合法 hook 保真）→ 成功

2. **cross_day 真实日期 API**
   - 改前：`_cross_day_result` 调 `_cross_day_prepare` 且写 `current_day`/`story_flags`
   - 改后：`_cross_day_exec` 只调真实 API（`advance_day()` 推进 daily/weekly/none/revive），前置日期由 run_registry_case 显式调 `_cross_day_prepare` 准备；`_cross_day_exec` 加入 FLOW_FIRST（禁写终态）
   - 修正：maid_combat_stone cross_day 从 none 改 daily（advance_day 每日重置其 available）

3. **N8 按序断言**
   - `_save_load_result` 拆分 4 错误码：`STORY_SAVE_WRITE_FAILED` / `STORY_SAVE_LOAD_FAILED` / `STORY_SAVE_DEFAULT_MISSING` / `STORY_SAVE_VALUE_MISMATCH`
   - N8 按序：baseline 成功 → 变异 action 完整流程（首次/重复/跨日/save/load）成功 → 加缺字段 → 命中 `STORY_SAVE_DEFAULT_MISSING`

4. **测试隔离 finally**
   - 唯一 user:// 路径 + `_cleanup_save`（_ready 开头/末尾）+ `_exit_tree` 兜底 + `_assert_clean` 清理断言
   - 测试后无存档残留（验证）

**回归**：v1.38 专项 PASS；全量 60 RUN EXIT 0。
