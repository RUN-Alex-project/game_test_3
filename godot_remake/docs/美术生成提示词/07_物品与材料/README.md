# 物品与材料提示词

所有物品均是原创图标源图。网页生成建议 1024×1024；最终 64×64 PNG；透明背景优先，或 #FF00FF 抠图底。图标不含文字、数字、货币符号、UI 框或水印。

| `06_后期成长` | 挑战、幻兽、赛季材料 |

任何真正参与数值或掉落的 item_id 必须先经过相应版本的数据合同批准；本目录的资源提示词不等于自动新增物品。
