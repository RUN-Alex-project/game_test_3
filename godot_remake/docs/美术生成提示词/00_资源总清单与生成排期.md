# 资源总清单与生成排期

本清单回答“哪些图真正需要生成”。它将原有资源、2.x 候选资源和原创资源明确分开，避免为已有内容重复制作。

## 1. 三种来源

| 分类 | 处理方式 | 是否现在生成 |
|---|---|---|
| `reuse_existing` | 复用当前工程 1.03 已接入的 UI、人物、物品、地图或音频 | 否 |
| `extract_after_audit` | v1.42 对 2.2/2.3/2.4 完成文本/证据审计后，按需最小提取 | 否，不能预设为可用 |
| `original_generated` | 当前工程和审计后资源均不足时，按本目录逐图生成 | 是，按优先级 |

## 2. 不需要生成的内容

以下内容默认复用当前已签署资源，不能为了“看起来新”而重做：

1. 顶部 HUD、底栏、背包格、仓库格、现有商店格、关闭按钮、通用面板框、现有字体。
2. 玩家、当前两只幻兽、现有城镇 NPC、现有普通怪物、既有 Boss、原有地图和已有物品图标。
3. 已签署的既有战斗特效、声音、状态提示和 UI 几何。
4. 现有 1.03 内容的已接入资产；若需修复，应是独立修复任务，不应由新资源替代。

## 4. 总量与生成优先级

当前提示词库已覆盖 633 份独立可生成资源提示词，分批生成，不要求一次做完。实际导入以 PM/SE 审批的 manifest 为准。v1.42–v1.55 的逐版本覆盖边界见 [00_未来版本美术覆盖审计.md](00_未来版本美术覆盖审计.md)。

优先顺序：

1. A01–A12 对话头像。
2. B01–B06、B41–B47 冒险者、邮件和交易图标。
3. v1.42 审计完成后，再决定是否生成世界演员、章节地图、敌怪和 Boss。
4. 每个后续版本签署后，仅生成该版本真正缺失的核心资源；表情、动画、卡面、封面、覆盖层和剧情插图均已有预留，不缺图但不要求提前制作。

## 5. 文件和审批规则

1. 每一个 `asset_id` 只允许一个当前定稿源图；废弃版本必须保留在项目外的归档，不覆盖生产图。
2. 未生成、未裁切、未验收、未登记哈希的文件不能出现在 Godot 的 `assets/expansion/`。
3. 开发工程师只接收最终 `asset_manifest.json` 中的 ID、路径、尺寸、坐标、哈希、用途和批准状态。
4. 若 v1.42 后确认本地 2.3/2.4 已有同类可复用资产，应标记本提示词为 `not_needed_after_audit`，不再生成重复图。
