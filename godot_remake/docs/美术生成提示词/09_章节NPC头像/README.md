# 章节 NPC 对话头像

这些角色服务于 v1.48–v1.51 的扩展章节。每张是独立原创头像，最终裁切到 96×96；世界地图上的对应静态演员在 `03_世界演员/02_章节人物/` 中单独生成。

| ID | 身份 | 用途 |
|---|---|---|
| `npc_treeheart_warden` | 艾玛，树心守望者 | 树心与港口篇章的调查委托、分支与树心收束 |
| `npc_harbor_master` | 赫伯特，港务长 | 港口线索、船坞入口与周常委托 |
| `npc_smuggler_informant` | 赛恩，走私线人 | 港口分支、秘密追踪或公开举报 |
| `npc_tide_chronicler` | 薇拉，潮汐史官 | 潮汐神殿、Boss 前置、港口历史 |
| `npc_south_commander` | 玛格拉，南城指挥官 | 南部城邦、边境状态机、军功结算 |
| `npc_border_quartermaster` | 奥伦，边境军需官 | 补给提交、产业/商会联动、边境委托 |
| `npc_border_scout` | 费妮，边境侦察员 | 侦察阶段、遗迹目标、探索排行 |
| `npc_south_magistrate` | 艾德里安，南城执政官 | 南城支线、领地声望、终局后事件 |
| `npc_ice_custodian` | 伊莱娅，冰原守护者 | 冰原入口、抗性说明、元素试炼 |
| `npc_aurora_sage` | 诺希尔，极光贤者 | 极光圣所、元素 Boss、终局线索 |
| `npc_abyss_envoy` | 赛菲斯，深渊使者 | 深渊入口、回响、终局盟友选择 |
| `npc_echo_keeper` | 赫林，回响守书人 | 深渊回响资料、图腾试炼、终局回顾 |

在 v1.42 审计确认本地资源后，允许以合规的已批准本地资源替代某项生成资产，但不得以名称相似性自行决定。
