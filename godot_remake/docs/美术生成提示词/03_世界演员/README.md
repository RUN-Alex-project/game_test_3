# 世界演员提示词

本目录的资源用于地图中的静态交互演员，不是动画序列。当前 Godot 版本可先用静态站立帧；行走、攻击、受击等动画只有在独立动画任务签署后才追加。

统一导入规格：网页生成 1024×1024；最终为 128×160 PNG，角色位于画布下方中央，脚底接近 y=152；透明背景优先，或 #FF00FF 抠图底。

| 子目录 | 内容 | 生成时机 |
|---|---|---|
| `01_固定冒险者` | 12 名冒险者静态世界演员 | v1.44 日程/地图实际需要时 |
| `02_章节人物` | 如固定冒险者不能承担剧情职责时再启用 | 对应篇章签署后 |

严禁把世界演员直接缩小成对话头像，或把头像直接放大作地图角色。
