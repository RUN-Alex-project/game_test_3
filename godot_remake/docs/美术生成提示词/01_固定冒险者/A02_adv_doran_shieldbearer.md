# A02 固定冒险者头像：多兰，城防盾卫

- `asset_id`：`adv_doran`
- 最终路径：`res://assets/expansion/portraits/adv_doran.png`
- 网页生成尺寸：1024×1024；最终裁切：96×96。
- 用途：v1.43 名册、边境守备委托、领地协作。
- 背景：暗红与铁灰的城墙虚化背景。

## 可直接复制提示词

```text
为单机复古暗黑奇幻 RPG 生成一张原创固定冒险者对话头像。

角色：多兰，一名三十多岁的城防盾卫；男性，深褐短发，右眉有一条旧伤，方正脸型，表情沉稳严肃。穿沉重但磨损的铁灰色半身板甲，肩部有暗红布披肩，胸前只有一枚无文字的圆形铜扣；画面中只露出一小段磨旧盾牌边缘，不遮挡脸。

画面：方形胸像，人物居中略朝右，胸口以上，头盔不遮脸，安全边距充足。背景为极简石砌城墙和冷雾，远处可有极弱火把暖光但不得出现旗帜文字、军徽或其他人物。

风格：原创 2D 像素插画感，复古暗黑奇幻 MMORPG 氛围；铁灰、暗红、古铜为主，清晰硬朗轮廓，材质表现为磨损金属与粗织布，低饱和而可读。

约束：没有文字、数字、logo、水印、边框、UI、现代军装、枪械、科幻装甲、额外角色、夸张英雄姿势、写实摄影；不要模仿任何既有游戏角色。
```

## 验收

必须一眼识别为可靠的城防战士；伤眉、暗红披肩、铁灰甲和盾牌边缘不应在裁切后丢失。
