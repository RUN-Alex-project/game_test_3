# A11 固定冒险者头像：妮娅，幻兽研究员

## 可直接复制提示词

```text
为单机复古暗黑奇幻 RPG 生成一张原创固定冒险者对话头像。

角色：妮娅，一名年轻的幻兽研究员；女性，浅蓝灰短发，紫灰眼睛，神情兴奋又专注。穿干净的灰白短外套、冷青色围巾和暗金小扣带，掌心托着一枚小型、无符文、柔和发光的圆形魔晶；不要出现任何具体幻兽或实验器材。

画面：方形胸像，人物略朝右，胸口以上，魔晶处于下方且不遮脸。背景为极简冷青实验台轮廓和淡淡蓝绿色散景，不出现文字、试管、现代仪器或其他人物。

风格：原创 2D 像素插画感，复古暗黑奇幻 RPG；灰白、冷青、暗金、柔紫为主，细节清爽但仍符合暗黑奇幻世界。

约束：没有文字、数字、logo、水印、边框、UI、现代实验室、科幻全息屏、额外角色、写实摄影；不要复刻任何现有游戏角色。
```

## 验收

魔晶必须是抽象、无符文的柔光物体；人物要像研究员而不是法师或现代科学家。
