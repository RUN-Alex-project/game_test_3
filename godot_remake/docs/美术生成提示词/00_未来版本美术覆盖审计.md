# v1.42–v1.55 美术提示词覆盖审计

## 审计边界

本文件的“已覆盖”仅指：已经批准的未来任务书所明确或合理必需的视觉资产类别，已经各自拥有独立、可复制的原创生成提示词。它不表示所有提示词都应立即生成，也不表示 2.2/2.3/2.4 的候选资源已经获准复用。

- 覆盖对象：`v1.42_内容证据与数据合同.md` 至 `v1.55_平衡长测与发布候选.md`。
- 不覆盖对象：未写入任务书的新玩法、未来临时需求、声音文件、字体授权、现有 1.03 已签署资源的重绘。
- 生成原则：先走 v1.42 的本地资源审计；只有缺口明确、玩法签署后，才从本提示词库挑选最小集生成。

## 生成与验收门槛

1. 每次只选即将实现版本所需的最小资产集，不能批量把整个目录直接导入工程。
2. 先审计 `E:\魔域\2.2`、`2.3`、`2.4`；确认可合法、可追溯复用的资源必须登记为 `reuse_existing` 或 `extract_after_audit`，而不是重新生成。
3. 每一张最终图必须记录 `asset_id`、文件路径、像素规格、来源、用途、哈希、审批状态；未经审批的网页生成图只可放在项目外候选区。
4. DeepSeek V4 Flash 的开发任务只能收到纯文本 manifest 和资源路径，不能要求其查看、识别或评价任何图片。

## 本轮复核结论

就 v1.42–v1.55 已批准任务书而言，所有明确的视觉域均已有至少一个独立提示词入口；其中原先容易遗漏的装备/孵化外观、28 个特效动画表和领地事件插图已经补齐。这个结论以文件结构与 `asset_id` 审计为准，不把“生成提示词存在”夸大为“最终美术已经制作、审批或导入”。
