# 统一风格、尺寸与导出规范

## 1. 风格锚点

所有提示词均应保持以下共同点：

- 原创复古暗黑奇幻 RPG；清晰的 2D 像素插画感，非写实照片。
- 轮廓清楚、色块克制、材质可读；远看能辨认人物职业、怪物轮廓和地图路线。
- 主色为深蓝灰、铁锈红、古铜金、冷青绿；各章节按资源卡再加入专属强调色。
- 光源单一明确，禁止强烈镜面反射、现代霓虹、科幻面板、Q 版大头、过度油画笔触。
- 所有资产为原创；不得出现任何现有游戏的角色、Logo、地名、技能名或 UI 文本。

## 2. 生成和导出顺序

1. 先在网页版生成“风格校准图”：一名无名冒险者半身像，确认色彩、轮廓与清晰度。
2. 每个后续资产单独开启或复制同一上下文，粘贴对应提示词；如果网页版允许上传参考，只上传已批准的“风格校准图”，不要上传原版游戏资源。
3. 优先保存最高分辨率无文字版本；不要直接把网页预览图作为生产文件。
4. PM/SE 完成裁切、缩放、alpha 检查、哈希和 manifest 后，才移入 `assets/expansion/`。

## 3. 输出规格

| 类型 | 网页生成建议尺寸 | 最终 Godot 规格 | 背景 |
|---|---:|---:|---|
| 对话头像 | 1024×1024 | 96×96 PNG | 可保留深色背景 |
| NPC 头像表 | 2048×1024 | 每格 96×96 PNG | 可保留深色背景 |
| 世界演员/怪物 | 1024×1024 | 单元 128×160 或文档指定值 | 透明优先；否则 #FF00FF |
| Boss | 1024×1024 | 256×320 或文档指定值 | 透明优先；否则 #FF00FF |
| 地图背景 | 1400×1100 | 700×550 PNG | 不透明 |
| UI 图标表 | 1024×1024 | 每格 64×64 PNG | 透明优先；否则 #FF00FF |
| 特效表 | 1024×1024 | 每格 96×96 PNG | 透明优先；否则 #FF00FF |

## 4. 透明资源统一抠图背景

若生成平台没有可用的透明 PNG，请在提示词中保留以下段落：

```text
背景必须是完全均匀的 #FF00FF 洋红色抠图底，没有阴影、地面、渐变、纹理、反光或雾气。主体不得使用 #FF00FF，四周保留至少 10% 空白。
```

此颜色仅用于后续处理，绝不能作为游戏中的实际背景。

## 5. 通用负面约束

每张提示词都已经加入同一含义的限制。若网页版仍生成错误内容，追加：

```text
不要文字、数字、logo、水印、边框、UI、现代物件、枪械、科幻装甲、额外角色、重复肢体、模糊脸部、裁切掉头部或脚部、写实摄影、任何现有游戏角色。
```

## 6. 人工验收清单

每张图在进入项目之前确认：

1. 主体与指定 asset_id/用途相符，且没有额外人物或文字。
2. 外轮廓完整，关键部位未被画布裁切。
3. 背景、透明度、尺寸和裁切区域符合单独文档。
4. 与已批准样张相比颜色、明暗、像素密度没有明显跑偏。
5. 未出现原版角色、第三方标识、可识别商标或水印。
6. 文件已由 PM/SE 登记 hash、最终路径和审批状态。
