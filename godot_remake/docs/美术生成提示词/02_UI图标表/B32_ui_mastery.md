## 可直接复制提示词

```text
生成一枚原创复古暗黑奇幻 RPG UI 图标：一把短剑的抽象剑柄和三道围绕其旋转的古铜细环，剑刃只露出一小段。

构图：单个图标居中，主体占画布约 70%，四周保留透明安全边距；在缩小到 64×64 像素后仍要保持外轮廓清楚且容易辨认。

风格：原创 2D 像素插画感，复古暗黑奇幻 MMORPG 的小型物品/系统图标；配色以 旧银、古铜、深蓝灰 为主，色块克制、材质可读、不含 UI 边框。

背景必须完全透明；若平台不能透明，使用完全均匀 #FF00FF 背景，没有阴影、地面、渐变、反光、烟雾或纹理。主体不得使用 #FF00FF。

不要文字、数字、logo、水印、UI 边框、现代电子设备、现代应用图标、额外物体、完整人物、写实摄影或任何现有游戏资产。
```

## 验收

不能像现代升级箭头或成就图标。文件需保留清晰的 alpha 边缘或可干净去除的 #FF00FF 背景。
