# 魔域 1.03 Godot 重制

这是基于原 SWF 素材重新搭建的 Godot 4.6 工程，目标是逐步重建原游戏，并把物品、怪物、任务、掉落、幻兽和数值机制改成易于继续扩展的数据结构。

## 当前可运行内容

- 使用原游戏主城底图、角色和怪物素材。
- 卡萨诺城按 SWF 第12帧恢复11个原生NPC的身份、人物帧与坐标；修正杂货商错用经验导师外观、收藏家错图、公主误入主城和重复挑战者等问题。
- 700×550 原始逻辑分辨率，可随窗口缩放。
- 顶部人物卡、两张幻兽卡和地图卡按原SWF坐标布局；人物显示生命/体力/经验，幻兽卡提供召回与合体/解体。
- 底栏按原SWF绝对坐标布局，包含中文日期/星期、剩余时间、音乐复选框、垃圾箱及62×32的背包/装备/幻兽/技能/VIP三态按钮。
- 玩家可使用方向键或 WASD 移动。
- 背包按SWF恢复`(453,300)`、247×207和6×4可见格；仓库恢复`(208,220)`、247×287和6×6可见格。现有48格容量继续用紧凑分页承接，包含物品说明、数量显示、同类堆叠和跨容器交换。
- 拖动过程中不删除源物品，只在合法落点执行原子交换，避免物品消失。
- 999 亿金币和999亿魔石显示。
- 杂货商按SWF恢复333×207买卖双栏，收藏商店与收藏家分别使用167×207购买/出售窗；购买保留满背包回滚，出售标题可反复结算999亿金币或魔石，矿石也可在4×3出售格中按品质单卖。
- NPC对话按SWF `sprite882/shape834`恢复`(200,80)`、362×269杏色窗口，使用19类原生NPC头像、玩家头像、六行原生选项与橙色圆形关闭钮。
- 28 张场景地图；场景四周入口按SWF角色1071的原始41×90/90×41命中范围、方向与根坐标布局，使用绿字目的地、红字“进入/返回”直接切图，并校正草原五福娃、后花园、抽奖房、三组PK赛场、战魂封印谜宫、蜘蛛/王后分布、地下城入口与六段最终战结构。
- 点击地图怪物立即在原场景攻击，不打开独立战斗窗口；怪物使用原版80×8血条，左键普通攻击、右键施放已学会的最强主动技能，并保留伤害飘字、合体幻兽协战、死亡刷新和原地掉落结算。
- 野外怪物名称不再常驻堆叠；悬停时显示原版123×74信息框，包含名称/等级、战斗力和当前经验加成，并按怪物与人物战斗力关系变色。
- 雷鸣大陆至深渊迷宫恢复19种原版普通怪物、29个场景实例及原始等级/坐标/精灵帧；同种怪物的多个实例可独立点击开战。
- 普通怪、七个等级Boss、蜘蛛和蜘蛛王后已改用反查SWF得到的独立掉落算法；幸运值参与原版`baoli`倍率，掉落装备保存等级、品质、魔魂与洞数。
- 人物和幻兽生命会跨回合、撤退、换图和存档持续保留；敌人依次攻击第一只合体幻兽、第二只合体幻兽，最后攻击人物。
- 幻兽死亡扣10幸运；人物死亡扣10幸运和当前等级经验的5%，生命归零并返回卡萨诺城。果子可回满人物生命，新的一天会回满所有幻兽生命，爱的力量会同时回满人物与幻兽。
- 武器、头盔、项链、衣服、手镯、战靴六栏穿戴，支持独立装备实例、角色属性、升级成长和战斗力计算。
- 人物/装备窗口按SWF `sprite561/shape524`恢复`(210,85)`、243×289布局，六个64×64装备位可显示装备图标和说明，并可向左展开战斗力详细评定。
- 装备养成窗口按SWF `sprite662`恢复`(238,375)`、191×133原生布局；品质/魔魂必成、战魂50%激活、天魂/地魂及较低魂等级战斗力加成全部可操作。
- 战魂秘密任务按原版条件开放：全身六件装备均达到极品后由装备锻造师给出线索；戈壁探险家收取50,000魔石并消耗一整天时间送入战魂封印谜宫，击败随人物等级成长的无名氏可获得战魂之心。
- 幻兽独立实例、最多2只出征、独立合体/解体、等级/经验、人物等级+10限制、50级幻化转世和经验球训练。
- 幻兽背包按SWF恢复`(0,150)`、213×333和每页4只布局，使用原生幻兽头像，支持分页、出征/召回、右侧详情、六字改名及带确认的安全丢弃。
- 幻兽研究所按SWF `sprite827`恢复`(250,180)`、203×183原生布局：技术10级起步、20级解锁、上限300、产量任务每次+2；每天自动生产，跨周自动提升技术，奇异兽库存与购买完整接通。
- 所有出征幻兽提供总战斗力并获得怪物基础经验；只有合体幻兽把攻防并入人物并优先承伤，不再额外执行独立攻击。
- 军衔与爵位使用原版累计门槛和战斗力加成；Boss按修改规则结算10倍军功。
- 地图占领按爵位开放，每天只能挑战一次；挑战者不会错误常驻地图，点击
- 紧凑成长窗口接通军衔、爵位、每日功勋任务、金币捐献、99/999玫瑰、周日军饷、公主关系礼物及全部领取状态。
- 原版杏色任务簿统一显示三条任务、领取状态和九阶段主线目标；路线按钮会根据当前地图计算真实最短路线，并在地下城入口提示寻找日常任务官。
- 冰雪精英军功链、幻兽上交任务和三组独立 PK 赛场：仅星期六可报名，按人物等级自动进入 60/100/100以上组，同一天只能参赛一次；三档擂主均使用原版通用Boss站立、攻击和受击剪辑。
- 技能书学习、主动技能伤害、人物体力与技能消耗、体力不足退化普通攻击、斗志昂扬战斗力加成和关系技能“爱的力量”。
- 技能窗口按SWF恢复`(23,220)`、183×253和六个原生40×40图标栏，显示当前技能等级/效果，并可点击施放“爱的力量”。
- 公主100/200亲密度自动解锁1/2级爱的力量；周日礼物按关系阶段结算并防止重复领取。
- 原SWF背景音乐与界面、战斗、升级、赠花、幻兽等37段音效已接入。
- 原版日常任务官按星期提供任务入口；皇宫包含元帅、首相、公主、侍女、PK赛报名官和抽奖官，救出国王后国王才会返回皇宫。
- 后花园按原版要求至少达到勋爵才能进入，包含公主及两名独立侍女；丫环2提供一次性年猪交易，丫环1每天提供一个2,800魔石的高级战斗力石。
- 抽奖官可直接传送到抽奖房；8个宝箱均消耗28魔石和2点时间，按2%/5%/38%/55%四档随机获得幻兽、装备、技能书或材料。
- 地下城三层救王、原版爵位/魔石奖励、雪域边境星期门槛、国王六类魔军情报已接入。
- 公主每日聊天会按关系阶段赠送幻兽；知己礼物和侍女 5,888 魔石年猪交易均为可存档的一次性事件。
- 玩家待机、向下、向上、向左和向右分别使用原SWF独立素材及12fps的8/10帧时间轴，战斗使用原四帧挥剑动作；普通怪攻击恢复原版5像素横移，通用等级Boss使用两张186×173攻击帧和由SWF形状精确栅格化的123×148受击帧；死亡按原脚本立即移除场景实例。
- JSON 物品数据库。
- JSON v21 本地存档与读取，保存幻兽合体状态、人物体力、五福娃进度、人物/幻兽当前生命、当天时间、带品质矿石、六栏装备、PK 当日参赛、战魂谜宫、六类魔军及结局状态，并兼容旧字段和废弃地图 ID。
- 摧毁“魔的能量”后进入原版“游戏结束”评价页，显示天数、总/装备/幻兽战斗力、等级、军衔、爵位、关系、财富和综合评语。
- 雷鸣矿洞恢复四个原版矿点：每次消耗 1/15 天时间，产出品质 1～10 的金矿或银矿；杂货商按品质收购银矿，收藏家按品质收购金矿。
