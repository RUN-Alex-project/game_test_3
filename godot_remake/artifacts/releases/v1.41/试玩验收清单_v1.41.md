# 魔域1.03 Godot 重制版 v1.41 发布候选版 试玩验收清单

> 本清单供不看源码的用户按步骤试玩验证。每步格式：前置状态 → 操作 → 预期界面/资源/flag 变化 → 失败时记录信息。
> 全部通过后才把 v1.41 从候选标记为正式可试玩基线。

## 一、新游戏启动与基础

1. 未存档 → 启动游戏 → 应进入主场景（卡萨诺城），顶部人物/幻兽 HUD、底栏可见，无脚本错误。
2. 按方向键/WASD → 人物应在卡萨诺城移动，NPC 可点击。
3. 打开背包 → 应显示 48 格，初始果子/经验球在位。
4. 打开仓库 → 应显示 48 格空位。
5. 打开杂货商 → 应有买卖选项；出售物品每次金币增加 99,999,999,999。
6. 打开收藏家 → 应有买卖选项；出售每次魔石增加 99,999,999,999。
   （商店系统：杂货商金币 / 收藏家魔石，两套商店买卖可用。）
7. 打开装备窗 → 六栏装备空位可见。
8. 打开幻兽窗 → 出征/合体/幻化操作可用。
9. 打开技能窗 → 已学技能显示。
10. 打开研究所 → 技术/产量/库存显示。
11. 打开任务簿 → 任务列表显示。
12. 保存 → 状态栏提示"保存成功"；重启后读取 → 状态一致。

## 三、关键系统操作

- **背包满**：装满 48 格后领取掉落 → 应进入待领取队列，不丢失。
- **仓库满**：装满后存入 → 应拒绝，不丢失物品。
- **精炼**：品质/魔魂必成；战魂晶石 50%。
- **幻兽**：出征/合体/幻化/训练；死亡与复活。
- **技能**：主动技能施放、体力不足降级。
- **研究所**：产量任务，日上限 6。
- **存档**：保存→重启→读取，状态一致；旧档可迁移。

## 四、长流程

1. 新游戏 → 地下城三层 → 救王 → 国王回宫给情报。
2. 最终战六类敌人 → 跨日复活 → 主帅 → 能量 → 结局。
3. 五福娃完整流程（使者→草原→领取→最终）。
4. 战魂秘密完整流程（极品→探险家→谜宫→战魂之心）。
5. PK 一组代表 + 当天重复限制。
6. 领地最低/最高门槛代表流程。
7. 人物死亡回城、幻兽死亡、切图、战斗取消。
8. 旧档迁移、保存、重启再读取。

## 五、用户覆盖值验证

- 无限货币：出售每次 +99,999,999,999。
- 10 倍经验：打怪经验为原版的 10 倍。
- Boss 10 倍军功 / 普通 1 倍。
- 品质/魔魂必成、战魂晶石 50%。
- 玫瑰 99=+50 / 999=+250。
- 研究所上限 300、日产量 6。
- 蜘蛛技能书 30/50/60%、王后 40/40/20%、王后/60+ Boss 增强月光盒 50%。
